# 💬 Web Messenger

Учебный проект — веб-мессенджер.

---

## 🚧 Статус проекта

В разработке

---

## 📌 Описание

Список страниц:
* авторизация
* регистрация
* страница чата
* профиль пользователя и его редактирование
* 404
* 500

[Дизайн](https://www.figma.com/design/jF5fFFzgGOxQeB4CmKWTiE/Chat_external_link?node-id=0-1&p=f&t=snuopyuis4ueaJBC-0)

---

## 🛠️ Технологии

* TypeScript
* Vite
* Handlebars
* SCSS (Sass)
* БЭМ-методология

---

## 🚀 Установка и запуск

```bash
# установить зависимости
npm install

# запуск dev-сервера
npm run dev
```

---

## 📦 Сборка проекта

```bash
# production сборка
npm run build
```

---

## 📂 Структура проекта

```bash
src/
  pages/        # страницы приложения
  layout/       # layout'ы страниц
  blocks/       # UI-блоки по БЭМ
  styles/       # глобальные стили
  assets/       # изображения, шрифты, иконки
```

---

## 📖 Доступные страницы:

* `/main.html` — список всех страниц
* `/login.html` — авторизация
* `/register.html` — регистрация
* `/profile.html` — профиль
* `/profile-edit.html` — редактирование профиля
* `/password-edit.html` — смена пароля
* `/chat.html` — страница чата
* `/error.html` — страница ошибки 404
* `/not-found.html` — страница ошибки 500
