
## 📂 Структура проекта

```bash
src/
  ├── app/ # инициализация приложения, роутинг, стили
  ├── pages/ # страницы приложения
  ├── widgets/ # крупные UI-блоки, собирающие несколько фич и сущностей
  ├── features/ # пользовательские сценарии (авторизация, изменение       профиля и т.д.)
  ├── entities/ # бизнес-сущности приложения (user, chat, message)
    ├── chats/
    ├── message/
    └── user/
  ├── shared/ # переиспользуемый код
    ├── api/ # HTTP-клиенты и API-модули
    ├── config/ # конфигурация приложения
    ├── lib/ # утилиты, хелперы, базовые классы
    ├── store/ # глобальное состояние приложения
    ├── ui/ # базовые UI-компоненты
    └── styles/ # глобальные стили
  ├── assets/ # изображения, иконки, шрифты
  └── index.ts # точка входа
```

---

## 📖 Доступные страницы:

- `/` — авторизация
- `/sign-up` — регистрация
- `/settings` — профиль
- `/settings/profile` — редактирование профиля
- `/settings/password` — смена пароля
- `/messenger` — страница чата
- `/404` — страница ошибки 404
- `/500` — страница ошибки 500
